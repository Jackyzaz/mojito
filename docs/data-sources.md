# แหล่งข้อมูลสำหรับโมเดลทำนายน้ำท่วมหาดใหญ่

สำรวจเมื่อ 2026-10-04 · พื้นที่ศึกษา: ลุ่มน้ำคลองอู่ตะเภา (lon 100.2–100.7, lat 6.6–7.3), ตัวเมืองหาดใหญ่ (lon 100.35–100.55, lat 6.9–7.1)

**ข้อสรุปสำคัญ**
1. **ข้อมูลรายชั่วโมงที่ฝึกโมเดลได้จริงครอบคลุมช่วง 2012–2025** ส่วนเหตุการณ์ปี 2543 และ 2553 มีแค่ฝนรายวัน (ERA5, GHCN-D) กับค่าระดับน้ำสูงสุดรายปี ไม่มีระดับน้ำรายชั่วโมง
2. **label เชิงพื้นที่คุณภาพดีมีเฉพาะเหตุการณ์ พ.ย. 2568** ส่วนเหตุการณ์ปี 2547, 2548–49, 2549 และ 2559–60 มีแผนที่จาก MODIS ความละเอียด 250 ม. ใน Global Flood Database
3. **พยากรณ์ฝนให้ค่าต่ำกว่าจริงมาก** วันที่ 20 พ.ย. 2568 ฝนตกจริง 174 มม. แต่ ECMWF พยากรณ์ล่วงหน้า 1 วันได้ 28 มม. และล่วงหน้า 5 วันได้ 19 มม. โมเดลจึงต้องใช้ระดับน้ำต้นน้ำ ความชื้นในดิน และฝนสะสมช่วยด้วย ไม่พึ่งพยากรณ์ฝนอย่างเดียว
4. **ควรตัด Windy ออกจากข้อเสนอโครงงาน** รุ่นฟรีจงใจส่งข้อมูลที่สุ่มสลับมา รุ่นเสียเงินราคา €990/ปี และไม่มีข้อมูลย้อนหลัง Open-Meteo ให้ข้อมูลได้มากกว่าและฟรี

### 1.2 คลังไฟล์ CSV ของ HII (เหมาะดาวน์โหลดทีละมากๆ) [V]
`http://tiservice.hii.or.th/opendata/data_catalog/{water_level|hourly_rain|daily_rain}/YYYY/YYYYMM/<CODE>.csv`
- มีเฉพาะสถานีของ HII เอง (SLA*, ONE*, NPCT ฯลฯ) ระดับน้ำบันทึกทุก 10 นาที ช่วงปี 2012–ปัจจุบัน
- ข้อมูลปี 2012 ใช้รูปแบบคอลัมน์ต่างจากปีอื่น และมีช่องว่างเยอะ ค่าที่หายไปบันทึกเป็น `-` หรือ `-999`
- รายละเอียดสถานีอยู่ในไฟล์ `0all_stn_metadata.csv`

### 1.3 กรมชลประทาน (RID)
- **ศูนย์อุทกวิทยาที่ 8 รายงานรายวัน (POST, เปิดสาธารณะ) [V]** ใช้ได้ตั้งแต่กลางปี 2017 ระบุวันเป็นปี พ.ศ.
  ```
  curl -X POST "https://hyd-app-db.rid.go.th/webservice/getDailyWaterLevelListReportMSL.ashx?option=2" \

  ```
  การเรียกหนึ่งครั้งได้ข้อมูล 7 วันของ 77 สถานี ฝนเรียกผ่าน `getDailyRainfallListReport.ashx` ส่วนหน้าข้อมูลรายชั่วโมงยังไม่ได้ทดสอบ [?]
- **hydro-8.com (ไฟล์ PDF) [V]**
  - `MaxGH/MaxGH_X44.pdf` ระดับน้ำสูงสุดรายปี 1967–2025: **ปี 2000 = 8.77 ม., 2010 = 9.10 ม., 2025 = 9.97 ม.**
  - `Table_Water_X44.pdf` ปริมาณน้ำท่ารายเดือน 1967–2020
  - มีกราฟความสัมพันธ์ระดับน้ำกับปริมาณน้ำ (rating curve) ปี 2025 ให้ด้วย
- **telerid.rid.go.th/restapi** ใช้ดูรายชื่อสถานีได้ แต่ข้อมูลรายสถานีต้อง login [V]
- ถ้าต้องการข้อมูลรายวันก่อนปี 2017 ต้องทำหนังสือขอจากกรมชลประทาน งานวิจัยที่ผ่านมาก็ได้ข้อมูลด้วยวิธีนี้ [D]

### 1.4 กรมทรัพยากรน้ำ (DWR) [V]
- `POST https://telemetry.dwr.go.th/api/public/report/hour/{getRF|getWL|getFlow}` ส่ง body `{"dataLastUpdated":"2025-11-25T00:00:00+07:00"}` ได้ข้อมูลรายชั่วโมงของทุกสถานีครั้งละ 1 วัน
- **มีข้อมูลตั้งแต่ประมาณ เม.ย. 2025 เท่านั้น** สถานีที่เกี่ยวข้อง: TA200303 (อู่ตะเภาตอนบน), TA200304 (อู่ตะเภาตอนล่าง), TA200307 (ปากรอ)
- API ทางการ `/api/twsApi/v1/...` ต้องลงทะเบียนเพื่อขอ X-API-Key

### 1.5 กรมอุตุนิยมวิทยา (TMD) และข้อมูลฝนสถานีระยะยาว
- `data.tmd.go.th/api/ThailandMonthlyRainfall/v1/?uid=api&ukey=api12345&format=json&year=2010` ให้ฝนรายเดือนตั้งแต่ 2001 เช่น สนามบินหาดใหญ่ พ.ย. 2010 = 449.8 มม. ใน response นี้ฟิลด์ lat กับ lon สลับกัน [V]
- กรมอุตุฯ ไม่เปิดข้อมูลรายวันหรือรายชั่วโมงย้อนหลังแบบสาธารณะ
- **ทางเลือกคือ NOAA GHCN-Daily [V]:** `https://www.ncei.noaa.gov/data/global-historical-climatology-network-daily/access/TH000048569.csv` (หาดใหญ่ ปี 1973–ส.ค. 2025) และ `TH000048568` (สงขลา ปี 1943–2025) หน่วยฝนเป็น 0.1 มม. เช่นวันที่ 1 พ.ย. 2010 = 240.8 มม. มีวันที่ข้อมูลหาย

### 1.6 แหล่งอื่น
- **data.go.th (CKAN API) [V]:** HII มีชุดข้อมูล `flood-mark` (SHP ความสูงคราบน้ำท่วม), `flood-area` และ `hydro-historical-report` ส่วนจังหวัดสงขลามี `disaster_071` (พื้นที่ท่วมซ้ำซาก), `dpm01` (พื้นที่เสี่ยง) และ `disaster_081` (รายงานผลกระทบ)
- **hatyaicityclimate.org [V]:** `https://hatyaicityclimate.org/api/flood/cams` ให้รายการกล้อง CCTV 36 ตัว พร้อมพิกัด สถานะเตือนภัย เขียว/เหลือง/แดง และภาพล่าสุด เป็นข้อมูล real-time เท่านั้น ไม่มีย้อนหลัง
- **ระดับน้ำทะเลและน้ำขึ้นน้ำลง:** ไม่มีสถานีวัดจริงที่สงขลาที่เปิดให้ใช้ มีเพียงตารางน้ำขึ้นน้ำลงพยากรณ์ของกรมอุทกศาสตร์ ส่วนระดับทะเลสาบใช้ SLA005 ปากรอแทนได้

## 2. สภาพอากาศ ฝน และข้อมูลพยากรณ์

### 2.1 Open-Meteo (แนะนำเป็นแหล่งหลัก) [V]
ฟรีสำหรับงานวิจัยและการศึกษา ไม่ต้องใช้ key สัญญาอนุญาต CC-BY 4.0 จำกัด 10,000 ครั้ง/วัน ใช้ผ่าน Python package `openmeteo-requests`

| API | ใช้ทำอะไร | หมายเหตุ |
|---|---|---|
| **Historical** `archive-api.open-meteo.com/v1/archive` | ฝนและความชื้นในดิน (3 ชั้น) ย้อนหลังถึง 1940 | **ต้องใส่ `models=era5`** ถ้าใช้ค่า default ช่วงปีหลังๆ จะสลับไปใช้ IFS ทำให้ข้อมูลไม่สม่ำเสมอ |
| **Forecast** `api.open-meteo.com/v1/forecast` | พยากรณ์ 16 วัน (ECMWF IFS, AIFS, GFS) | ใช้เป็น input ตอนระบบทำงานจริง |
| **Ensemble** | พยากรณ์ ECMWF 51 สมาชิก | ใช้คำนวณความน่าจะเป็นที่น้ำจะท่วม |
| **Historical Forecast / Previous Runs** | ค่าที่พยากรณ์ไว้ในอดีต แยกตามจำนวนวันล่วงหน้า | GFS ตั้งแต่ 2021, IFS ตั้งแต่ 2024 ใช้ให้โมเดลเรียนว่าพยากรณ์มักคลาดเคลื่อนแค่ไหน |
| **Flood (GloFAS v4)** `flood-api.open-meteo.com/v1/flood` | ปริมาณน้ำท่าในแม่น้ำ (river discharge) และพยากรณ์ จุดคลองอู่ตะเภามีข้อมูลตั้งแต่ 1997 (ดึงจริง 2026-10-04) | **ใช้จุด (7.025, 100.425)** ซึ่งตรงกับคลองอู่ตะเภาสายหลัก จุดที่ใกล้ตัวเมืองที่สุดเป็นลำน้ำสาขา |

### 2.3 แหล่งอื่น
- **ERA5 / ERA5-Land ผ่าน Copernicus CDS** (`cdsapi`, สมัครฟรี): ใช้เมื่อต้องการข้อมูลแบบกริดหรือตัวแปร runoff
- **GloFAS ผ่าน EWDS**: ใช้เมื่อต้องการข้อมูลกริด discharge เต็มชุด
- **ECMWF Open Data** และ **NOAA GFS**: พยากรณ์ดิบรูปแบบ GRIB2 เก็บไว้ออนไลน์แค่ไม่กี่วัน ต้องเก็บเอง ใช้ Open-Meteo แทนได้
- **ดัชนีภูมิอากาศ** ใช้เป็น feature ระดับฤดูกาล [V]:
  - ONI `cpc.ncep.noaa.gov/data/indices/oni.ascii.txt` (ปี 2010 เป็นช่วงลานีญา)
  - MJO OMI `psl.noaa.gov/mjo/mjoindex/omi.1x.txt`
  - ไฟล์ BoM RMM หยุดอัปเดตตั้งแต่ปี 2024 ไม่ควรใช้

## 5. ข้อเสนอการนำไปใช้

### Training set
- **โมเดลเวลา (ทำนายระดับน้ำ X.44 ล่วงหน้า 1–5 วัน)**
  - ช่วงข้อมูล: 2012–2025 ใช้ HII CSV และ ThaiWater, กรมชลฯ รายวันตั้งแต่ 2017
  - feature:
    - ระดับน้ำต้นน้ำ X.90 และ X.173A
    - ระดับทะเลสาบ SLA005
    - ฝน ERA5 / IMERG เฉลี่ยทั้งลุ่มน้ำ
    - ความชื้นในดินจาก ERA5
    - ปริมาณน้ำท่าจาก GloFAS
    - ดัชนี ONI
- **โมเดลพื้นที่ (ความน่าจะเป็นที่แต่ละช่อง H3 จะท่วม)**
  - feature: HAND, TWI, ระยะห่างจากลำน้ำ, การใช้ที่ดิน, ความหนาแน่นทางน้ำใน OSM รวมกับระดับน้ำ X.44 ที่ทำนายได้
  - label: EOS-RS พ.ย. 2568 สำหรับเขตเมือง, GFM นอกเมือง และเหตุการณ์ใน Global Flood Database
- **ตรวจสอบกับเหตุการณ์ใหญ่ในอดีต**: ปี 2543 และ 2553 ใช้ฝน ERA5 หรือ GHCN-D กับระดับน้ำสูงสุดรายปีของ X.44 ตรวจว่าโมเดลจับเหตุการณ์ได้หรือไม่ ใช้เป็นชุดทดสอบเท่านั้น

### Real-time feed (ต่อจาก ETL ของ sindhu)
- ข้อมูลล่าสุดจาก ThaiWater `waterlevel_load` / `rain_24h` และ RID / DWR แบบ POST
- พยากรณ์ฝนจาก Open-Meteo Forecast และ Ensemble
- พยากรณ์ปริมาณน้ำท่าจาก GloFAS
- ฝนที่ตกไปแล้วจาก GSMaP / IMERG Early

### ความเสี่ยงที่ควรระบุในรายงาน
- label เชิงพื้นที่ความละเอียดสูงมีแค่เหตุการณ์เดียว (2568) โมเดลพื้นที่อาจไม่ generalize ไปเหตุการณ์อื่น ต้องแบ่ง train/test ตามพื้นที่ (spatial split) และอธิบายข้อจำกัดนี้ให้ชัด
- ข้อมูลระดับน้ำรายชั่วโมงมีน้ำท่วมใหญ่เพียงครั้งเดียว ข้อมูลจึงไม่สมดุลมาก (class imbalance) ควรทำนายเป็นค่าระดับน้ำ (regression) แล้วค่อยแปลงเป็นระดับเตือนภัย ดีกว่าทำ classification ท่วม/ไม่ท่วมตรงๆ
